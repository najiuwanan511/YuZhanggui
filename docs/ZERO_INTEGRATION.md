# Zero 1.7.11 对接说明

本功能把闲鱼订单作为独立来源接入 Zero，不会创建微信会员，也不会扣减或退回微信积分。

## 配置顺序

1. 启动 Zero 1.7.11，在“软件设置 → 闲鱼对接”中启用接口，生成 API Token 和回调密钥。
2. 在 Zero 中把闲鱼商品 ID 映射到对应项目；只有一个闲鱼账号时，账号 ID 也可以留空。
3. 在 Zero 分别点击“复制”，粘贴到 YuZhanggui 的“设置 → Zero 转单对接”；两边的 API Token 和回调密钥必须逐字一致。
4. 在 YuZhanggui 点击“复制”回调地址，粘贴到 Zero 的“结果回调地址”，并在两端保存配置。
5. 点击 YuZhanggui 的“测试连接”。
6. 打开目标闲鱼商品配置，启用自动发货，将发货方式改为“Zero 异步转单”，设置每件需提交条数。

Docker 中的 YuZhanggui 访问同一台 Windows 主机上的 Zero 时，Zero 地址通常使用：

```text
http://host.docker.internal:Zero端口
```

跨设备访问时应使用 HTTPS，并确保防火墙只开放必要端口。Token 和回调密钥不要发给他人。

## 订单流程

1. 买家付款后，系统建立等待提交会话。
2. 买家逐条发送内容，系统按消息 ID 去重并回复当前进度。
3. 收齐后，订单内容原样逐条提交给 Zero；网络失败会持久化重试。
4. Zero 根据商品映射建立订单并执行原有转发、回执判断。
5. Zero 用 HMAC-SHA256 签名回调每一条结果。
6. YuZhanggui 校验签名、订单、买家、会话和明细编号；全部结束后只向原买家回复一次汇总结果。

数据库迁移 `V35__add_zero_bridge.sql` 会自动创建桥接订单、提交明细和回调事件表。升级前仍建议按原项目方式备份 MySQL 数据库。
