# 2026-10-12 源码与发货流程检查报告

基于 main `ba8acce9f4446713f42e9ec8a6faff26bb10c0a6` 检查并修复，版本为 **2.3.23**。以下记录发布前的本地验证结果；正式发布状态以 GitHub Release 和对应工作流为准，未部署飞牛服务器。

## 已修复的问题

| 范围 | 确认的问题与修复结果 |
| --- | --- |
| 凭证恢复 | 旧 Token 未变化时直接结束恢复，核验失败后永久挂起。现在有限次数重新协商，失败保留凭证；核验失败先等待 5 分钟、连续失败后 30 分钟，更新 Cookie 后提前恢复安全的未发送订单。 |
| 历史任务 | V37 恢复旧核验挂起任务，排除已发送、退款、自提、发送结果待核对等订单；正常账号才领取。 |
| 发货状态 | 工作线程提前改成 FAILED/COMPLETED，调度器要求 PROCESSING 才能重试/收尾。现在工作线程只写结果，调度器完成最终转换；校验租约归属与有效期。 |
| 重复发送 | 图片缺少逐张租约检查及外部发送标记；文本 ACK 不明或发送后抛异常可能被重试。现逐次检查，外部发送后结果不确定转人工核对。 |
| 交易状态 | 排队任务未拦截已知退款、关闭、待付款、已发货、已完成状态。现停止领取，并在每次外部发送前检查数据库状态；已开始发送的过期任务保留人工核对路径。 |
| 发货内容完整性 | 虚拟发货 API 静默截断超过 200 字符的文本、超过 3 张的图片。现明确拒绝超限内容，不再用残缺内容发货并显示成功。 |
| Cookie 一致性 | 支持分号后无空格的 Cookie；同步签名字段；响应合并在账号凭证锁内进行，旧请求响应不能覆盖新登录关键凭证。 |
| Cookie 请求 | 尊重服务端过期删除；刷新客户端停止自动跟随重定向，避免把导入的凭证转发至重定向地址。 |
| 页面提示 | 手动 Token 刷新无变化不再显示“仍然有效”；运行版本高于 Release 时明确提示。 |
| 在线更新 | Zero 提交/回复任务纳入业务等待，维护期间停止领取；发布前核对标签、后端、前端、锁文件版本，安装前校验 JAR 内部版本；镜像带构建提交。 |
| 版本与依赖 | 前后端统一 2.3.23，使已运行 2.3.22 的用户能在正式发布后看到升级；更新兼容前端依赖及 Vue lint 插件，MyBatis 分页方言修正为 MySQL。 |
